# Подключения к базам данных

## Менеджер и группы

`dbManager` — компонент `app\components\db\ConnectionManager`, подключённый в веб-, консольной и тестовой конфигурации. Группы описываются в `config/db/groups.php`:

```php
return [
    'course' => [
        'moy_ogorod' => require __DIR__ . '/course/moy_ogorod.php',
    ],
];
```

Для добавления БД в группу добавьте именованный элемент в этот массив. Менеджер создаёт объекты лениво, сохраняет их для повторного использования и не открывает соединение при получении объекта. `getConnection('db')` возвращает основное подключение приложения.

```php
$group = Yii::$app->dbManager->getGroup('course');
$db = $group->getConnection('moy_ogorod');
// Тот же объект доступен по полному имени:
$db = Yii::$app->dbManager->getConnection('course:moy_ogorod');
$db = Yii::$app->get('course:moy_ogorod');
$group = Yii::$app->get('course');

$cursor = $group->iterate();
do {
    $name = $cursor->key();
    $db = $cursor->current();
    // Обычные операции Yii с конкретным $db.
} while ($cursor->next());
```

Каждый `iterate()` создаёт независимый обход. Именованный доступ не меняет его позицию. После завершения `current()`/`key()` выбрасывают исключение; `rewind()` возвращает к началу. Неизвестное имя и пустая группа — ошибки. Группа не является `Connection`: запросы и транзакции выполняются только через конкретное подключение.

## Файлы подключений

Для одного курса также доступна команда `php yii migrate-course --db=course:moy_ogorod`. Она использует `migrations/course` и отклоняет указание другой директории. Без `--db` и без собственного назначения миграции используется основное подключение `db`.

Каждая БД имеет отдельный PHP-файл, возвращающий массив конфигурации Yii DB Connection:

```text
config/db/
  db.php                   — основная БД
  course/
    moy_ogorod.php          — БД курса «Мой огород»
```

Для нового курса добавляется `config/db/course/<alias>.php` с такой же структурой массива. Конфигурации независимы: каждая содержит собственные DSN, пользователя, пароль и кодировку. Чтение файла не открывает соединение.

`moy_ogorod.php` настроен на `nl_course_moy_ogorod` на текущем сервере. Параметры можно переопределить переменными окружения `NL_MOY_OGOROD_DB_DSN`, `NL_MOY_OGOROD_DB_USER`, `NL_MOY_OGOROD_DB_PASSWORD`. Секреты следует задавать в окружении сервера, не добавляя их в репозиторий. У веб-приложения и консольных команд должно быть одинаковое окружение подключения.

Веб-приложение, консоль и тестовая конфигурация используют новый путь основной БД. Текущие сервисы ещё не переключены на базу курса: контекст курса и перенос данных — следующие этапы. Команда `php yii migrate` по умолчанию использует основную БД и папку `migrations/main`. Для курса: `php yii migrate --db=course:moy_ogorod --migrationPath=@app/migrations/course`; для всех зарегистрированных курсов: `php yii migrate --db=course --migrationPath=@app/migrations/course`. Явный `--db` должен входить в назначение `getConnections()` миграции, иначе команда завершится исключением; без `--db` выполняется всё назначение. Применение миграций выполняет владелец проекта.

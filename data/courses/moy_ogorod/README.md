# Курс «Мой огород»

Курс на русском языке для начинающих огородников. Три категории по 13 тем, каждая тема содержит 20 вопросов, каждый вопрос — 10 вариантов и ровно один правильный ответ. Итого: 39 тем, 780 вопросов, 7 800 вариантов.

- `course.md` — полный читаемый банк вопросов с вариантами и отмеченными правильными ответами, оглавлением и источниками.
- `course.json` — полный структурированный банк для загрузки, UTF-8, `format_version: 1`. Иерархия: `categories → topics → questions → answers`. Правильность в этом исходном формате задаёт логическое поле `is_correct`. При импорте идентификаторы правильных вариантов записываются в `right_answer.answer` как `{"choice": [...]}`; в `answer_option` поля `is_correct` нет.
- `source.txt` — редактируемые авторские пары «вопрос|правильный ответ», сгруппированные по категориям и темам.
- `build.py` — воспроизводимая сборка JSON и Markdown средствами стандартной библиотеки Python. Неверные варианты выбираются из банка ответов той же темы; порядок детерминирован. В итоговом JSON все варианты уже записаны, миграция ничего не генерирует. Каждая позиция правильного ответа встречается 78 раз во всём курсе.

Файл содержит вопросы по понятиям, распознаванию признаков, практическим решениям и расчётам. Сроки садовых работ не привязаны к одному региону. Арифметические задания не являются нормами внесения удобрений. Применение средств определяется местной регистрацией и этикеткой конкретного продукта. Источники перечислены для проверки принципов и дальнейшего чтения; иностранные рекомендации не устанавливают разрешения на препараты для России.

## Загрузка

После разделения БД миграция `migrations/main/m260915_000001_create_moy_ogorod_course.php` только добавляет запись курса в основной каталог. Команда `php yii migrate` больше не загружает материалы.

Команда `php yii migrate-course --db=course:moy_ogorod` создаёт структуру курса и загружает материалы в БД из `config/db/course/moy_ogorod.php`, зарегистрированной в `config/db/groups.php`. Все применения миграций выполняет владелец проекта.

Миграция `m260927_000002_load_moy_ogorod` назначена только подключению `course:moy_ogorod`. Она проверяет исходный банк через `migrations/support/MoyOgorodData.php` и загружает 3 категории, 39 тем, 780 вопросов и все 7 800 вариантов. Все вопросы получают тип «4 варианта, 1 ответ» с категорией `QuestionTypeCategory::CHOICE`, несмотря на сохранение 10 вариантов. Для каждого вопроса создаётся один правильный ответ в JSON.

Это первоначальное заполнение: таблицы `question_type`, `category`, `topic`, `question`, `answer_option`, `right_answer`, `question_topic` должны быть пустыми. Откат удаляет импортированные ID в обратном порядке зависимостей; ссылки из пользовательских попыток препятствуют откату. Миграция не переносит данные из прежних таблиц `course_moy_ogorod_*` и не переключает сервисы приложения.

## Изменение материалов и проверки

Материалы можно редактировать через `source.txt` и пересобирать командой `python data/courses/moy_ogorod/build.py`, проверяя результат в `course.md`. Перезагрузка в БД потребует отдельного импортера с сохранением пользовательских тестов и истории.

`php tests/migration-routing.php` проверяет выбор БД и разделение миграций без подключения к БД. `php tests/moy-ogorod-import.php` проверяет импорт, сохранение всех вариантов, правильные ответы и откат на SQLite в памяти. Старые `tests/moy-ogorod.php` и `tests/learning-schema.php` рассчитаны на прежнюю общую схему и импорт через миграцию; для новой архитектуры их ещё предстоит адаптировать.
